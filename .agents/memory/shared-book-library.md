---
name: Shared book library
description: Requested permanent book repository separate from the site's thinker profiles.
---

Dr. Kuczynski wants a standing library for books not written by any of the site's represented thinkers. Adding such books must not require adding their authors as thinker profiles. Users should be able to query the books and have existing thinkers discuss them; Freud and Jung discussing a library book is an example, not an exhaustive scope.

**Why:** The user explicitly distinguished adding a permanent repository from adding another person to the site.

**How to apply:** Treat this as a requested capability, not an implemented feature. Keep library-book content distinct from the primary writings that ground each participating thinker's position.
