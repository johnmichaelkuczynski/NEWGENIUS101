Genius 101 API

Self-contained guide for connecting another application to the published Genius 101 Kuczynski response API.

This describes the route implemented in the project and the published URL obtained from deployment metadata. An authenticated production request has not been verified for this guide. This file contains no credentials.

Scope: This key authenticates a request for a generated Kuczynski answer. It does not provide a general Genius 101 search API, raw source passages, or independently verified citations. Do not invent a search endpoint or represent generated quotations as independently retrieved evidence.

Connection details

Published base URL
https://genius101.xyz
Method and path
POST /api/external/kuczynski
Full request URL
https://genius101.xyz/api/external/kuczynski
Content type
Content-Type: application/json
Preferred authentication
Authorization: Bearer YOUR_KEY
Alternative authentication
X-API-Key: YOUR_KEY

Replace YOUR_KEY with the key already stored in the calling application's secure server-side secrets. Never put it into browser JavaScript, a public repository, a URL query string, logs, or a prompt. The receiving Genius 101 server must also recognize that key: either its shared GENIUS_API_KEY secret must match, or the key must be a valid, unrevoked Genius 101-issued API key. Adding a secret only to the calling app does not provision it on the receiving server.

Request body

{
  "message": "Explain your view of the relationship between evidence and belief.",
  "maxWords": 750,
  "quotes": 3,
  "stream": false
}
message
Required, nonempty string, maximum 20,000 characters. The current question or instruction.
history
Optional array of objects with role (user or assistant) and content (string). The API is stateless: the caller sends prior turns each time. At most the last 20 items are used; each content string is truncated to 8,000 characters.
maxWords
Optional target word count; defaults to 750 and is bounded to 50–5,000. It is a generation target, not a guaranteed exact count.
quotes
Optional requested number of quotations; defaults to 3 and is bounded to 0–20. Set to 0 to request none. This is an instruction to the model, not proof that a quotation was retrieved or verified.
stream
Optional boolean, defaults to false. Set to true for a server-sent event response.

Response

With stream: false, a successful response is JSON in this shape:

{
  "response": "Generated answer text...",
  "character": "kuczynski",
  "words": 123
}

The response field is generated prose. It does not carry source passage IDs, offsets, edition details, or independently checked citations. With stream: true, the response is text/event-stream: successive data: {"content":"..."} events supply text, followed by data: {"done":true}. A streaming error can arrive as data: {"error":"Generation failed"}.

Server-side example

This Node.js example reads the key from the calling app's environment. It never prints the key.

const key = process.env.GENIUS_API_KEY;
if (!key) throw new Error("Configure GENIUS_API_KEY in server-side secrets");

const response = await fetch("https://genius101.xyz/api/external/kuczynski", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${key}`
  },
  body: JSON.stringify({
    message: "Explain your view of the relationship between evidence and belief.",
    maxWords: 750,
    quotes: 0,
    stream: false
  })
});
if (!response.ok) {
  throw new Error(`Genius 101 request failed with HTTP ${response.status}`);
}
const data = await response.json();
console.log(data.response);

Errors and limitations

  • 400: missing, invalid, or overlong message.
  • 401: missing, unrecognized, or revoked API key. Confirm that the receiving deployment recognizes the key; do not display it for debugging.
  • 429: per-key rate limit of 30 requests in a rolling 5-minute window.
  • 500: authentication or generation error on the server; retry cautiously rather than fabricating an answer.

Some other Genius 101 routes serve thinkers, quotations, or argument records, but they are not part of this key's documented Kuczynski response contract. This guide does not claim a citation-bearing search route exists. If an application must retrieve and cite exact primary-source passages, a separate documented retrieval API with stable source references must be built and verified first.

Instructions to paste into another app's agent

Use the Genius 101 Kuczynski response API at https://genius101.xyz/api/external/kuczynski. Send POST with Content-Type: application/json and Authorization: Bearer <GENIUS_API_KEY from this app's server-side secrets>. Body: {"message":"your question","maxWords":750,"quotes":0,"stream":false}. Read the generated answer from the response field. Do not view, print, expose, or change the key. If the request returns 401, report that the published Genius 101 server did not accept the credential; do not invent a replacement endpoint. This API generates answers; it does not return independently verified source passages or citations. Do not claim otherwise or make up a search path.
