Kuczynski API

One key for generated Kuczynski answers and read-only access to the Kuczynski source corpus.

Availability: The retrieval endpoints documented below were added to the project code. They will not be available at the published URL until the server changes are restarted and the project is published. Do not tell another app they are live before that happens. No key is included in this document.

Connection and authentication

Published base URL: https://genius101.xyz
Path prefix: /api/external/kuczynski-standalone
Header: Authorization: Bearer YOUR_KUCZYNSKI_API_KEY or X-API-Key: YOUR_KUCZYNSKI_API_KEY.

Use the already stored KUCZYNSKI_API_KEY in the calling application's server-side secrets. The same key must be configured on the receiving Genius 101 server. Never paste it in chat, put it in client-side code, or log it. This key is distinct from GENIUS_API_KEY and from keys for other thinkers. All endpoints below require this key. Generated answers are limited to 30 requests per 5 minutes; the read-only corpus endpoints share a separate 300-request-per-5-minute limit to allow paginated exports.

Source records

All list endpoints are GET requests with optional q (case-insensitive literal text search, up to 200 characters), limit (1–100, default 20), and offset (0–100000, default 0). The lists for passages, quotes, arguments, and positions also accept sourceId to filter by source. A successful list response has category, items, limit, offset, hasMore, and nextOffset. Continue requesting the next offset while hasMore is true. An empty result is an empty items array; do not substitute AI-generated text.

  • GET /api/external/kuczynski-standalone/sources — source catalog: sourceId, title, sourceFile, passageCount. The optional q searches titles and filenames.
  • GET /api/external/kuczynski-standalone/sources/:sourceId — full original source record: sourceId, title, sourceFile, content. Returns 404 when the ID does not belong to Kuczynski.
  • GET /api/external/kuczynski-standalone/passages?q=belief&limit=20 — verbatim stored source chunks: id, text, chunkIndex, sourceId, sourceTitle, sourceFile. This is the correct endpoint for authentic writing samples to load into Box A. Without q, it lists all passages in stable source and chunk order.
  • GET /api/external/kuczynski-standalone/quotes?q=belief — stored quote records: id, text, topic, and source details when linked. Stored quote records should be checked against their source before being presented as verified verbatim quotations.
  • GET /api/external/kuczynski-standalone/arguments?q=belief — structured, derived argument records: id, argumentType, premises, conclusion, topic, importance, and source details where linked. Premises and conclusions are not verbatim quotations.
  • GET /api/external/kuczynski-standalone/positions?q=belief — derived position records: id, text, topic, and source details where linked. Not verbatim quotations.

sourceId identifies an underlying source text; chunkIndex identifies a passage's position within that source. These are source references, not printed page numbers. Missing source links are returned as null, not fabricated.

Generated answer (existing endpoint)

POST /api/external/kuczynski-standalone with Content-Type: application/json and a body like:

{"message":"What is your view of belief?","maxWords":750,"quotes":0,"stream":false}

The JSON response contains response, character, and words. This is AI-generated output, not an authenticated source passage. history can supply up to 20 prior turns (each with role and content). maxWords ranges from 50 to 5000; quotes from 0 to 20. With stream: true, the endpoint emits server-sent data events with content followed by done.

Server-side example: load authentic paragraphs into Box A

const key = process.env.KUCZYNSKI_API_KEY;
if (!key) throw new Error("KUCZYNSKI_API_KEY is not configured");

const url = new URL("https://genius101.xyz/api/external/kuczynski-standalone/passages");
url.searchParams.set("q", "belief");
url.searchParams.set("limit", "10");
const response = await fetch(url, {
  headers: { Authorization: `Bearer ${key}` }
});
if (!response.ok) throw new Error(`Kuczynski API returned HTTP ${response.status}`);
const result = await response.json();
// Store sourceId and chunkIndex alongside each original passage.
const boxA = result.items.map(passage => passage.text).join("\n\n");

For varied tests, page through results using nextOffset and retain each record's source metadata. Do not replace an empty result with generated prose. For the complete text of a work, request its sourceId from /sources, then fetch /sources/:sourceId.

Error handling

400 means an invalid request or query parameter; 401 means the key is absent or rejected; 404 means a source ID was not found in Kuczynski's works; 429 means the shared per-key rate limit was reached; 503 means the receiving server has no Kuczynski key configured; 500 means retrieval or generation failed. The current app code has not been restarted or published as part of writing this guide.
