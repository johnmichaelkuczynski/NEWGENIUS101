# Lao Tzu texts

Drag and drop Lao Tzu's works into this folder as `.txt` files.

Use the book title as the filename, for example `Tao Te Ching.txt`.
The folder name `lao_tzu` identifies the author; no author prefix is needed in the filename.

Adding files here does not itself index them in the database. Ask the agent to import the uploaded Lao Tzu texts after uploading.
